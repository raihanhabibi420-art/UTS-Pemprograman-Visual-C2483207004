Deskripsi Aplikasi

Kasir Kantin Kampus merupakan aplikasi desktop sederhana yang dibuat menggunakan bahasa pemrograman Java dengan library Java Swing melalui Apache NetBeans IDE.
Aplikasi ini digunakan untuk membantu proses transaksi pembelian makanan dan minuman di kantin kampus. Pengguna dapat memasukkan nama makanan atau minuman, harga satuan, jumlah pembelian, dan uang pembayaran. Selanjutnya, aplikasi akan menghitung total harga serta uang kembalian secara otomatis.

Aplikasi ini dibuat untuk memenuhi tugas Ujian Tengah Semester (UTS) mata kuliah Pemrograman Visual.

Fitur Aplikasi

1. Memasukkan nama makanan atau minuman.
2. Mengisi harga satuan.
3. Mengisi jumlah pembelian.
4. Menghitung total harga secara otomatis.
5. Menghitung uang kembalian berdasarkan pembayaran.
6. Menampilkan pesan apabila data belum lengkap atau pembayaran kurang.
7. Tombol Reset untuk mengosongkan kembali formulir.

Komponen Java Swing

Komponen yang digunakan dalam aplikasi ini meliputi:

- JFrame sebagai jendela utama aplikasi.
- JLabel untuk menampilkan keterangan.
- JTextField untuk memasukkan data transaksi.
- JButton untuk menjalankan perintah Hitung, Bayar, dan Reset.
- JOptionPane untuk menampilkan pesan informasi dan peringatan.

Cara Menjalankan Aplikasi

1. Buka Apache NetBeans IDE.
2. Pilih menu File, kemudian Open Project.
3. Pilih folder project "KasirKantinKampus".
4. Tunggu sampai project berhasil dibuka.
5. Buka file "FormKasir.java".
6. Jalankan aplikasi dengan menekan tombol Run Project.
